## ACK Boundaries

Separate exact ACK is required for:

- Coinbase poll or live order inspection.
- Submit, cancel, replace, reprice, or new order.
- Lifecycle apply or terminal closeout apply.
- Local repair apply or manual position close.
- Service restart or runtime configuration mutation.
- `.env`, prompt, strategy, risk, config, or parameter mutation.
- Optimization, parameter search, parameter approval, or learning-to-execution.
- `sudo`, `apt install`, or system package mutation.

## Stop Conditions

Stop when:

- local state unexpectedly shows open orders or active D.3 exits;
- a route would cross live/state/system/config/parameter boundaries;
- a safety validator blocks a report;
- tests fail in a way that could affect trading safety;
- one safe bundled sprint is complete.
